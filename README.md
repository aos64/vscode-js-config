# vVisual JS Get
A Powershell script that will setup a Visual Studio Code + Node.JS development environment for unprivelliged users.

**Instructions**

1. Run the script
2. Once the VSCode installer appears, click through it until you reach the end.
3. Unselect the  "Run Visual Studio Code" option.
4. Once the script window closes, run VSCode.
5. Enter the newly created js.env folder
6. Welcome to your new dev box.
